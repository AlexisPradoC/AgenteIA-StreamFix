# StreamFlix — Glosario

| Término | Significado |
|---|---|
| Contenido | Una película o serie del catálogo |
| Historial | Registro de lo que un usuario vio y hasta dónde |
| Progreso | Porcentaje visto de un contenido (0–100) |
| Calificación | Puntaje de 1 a 5 que un usuario da a un contenido |
| Género preferido | Género que el usuario marcó como de su interés |
| Recomendación | Contenido sugerido a un usuario según sus gustos |
| Afinidad | Qué tan bien encaja un contenido con los gustos del usuario |
| Popularidad | Qué tan visto o bien valorado es un contenido en general |
| Clasificación de edad | Edad mínima recomendada para ver un contenido |
| RN | Regla de negocio |
| HU | Historia de usuario |
| Endpoint | Ruta de la API a la que el frontend hace una petición |
| Controller / Service / Repository | Las tres capas del backend (ver `plan.md`) |
